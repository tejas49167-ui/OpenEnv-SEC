# Examples

This directory contains realistic usage flows for Sec-OpenEnv.

- `clients/async_api_walkthrough.py`: typed client example against a local server
- `clients/http_api_smoke.py`: raw HTTP workflow for smoke testing and demos
- `benchmark/run_single_episode.py`: local environment walkthrough without starting the server
- `evaluate_multiple_models.py`: lightweight multi-model evaluation loop for repeated benchmark runs
- `local_cyber_triage.py`: original lightweight example preserved for continuity
