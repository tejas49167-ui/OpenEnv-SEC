# Code of Conduct

## Our Commitment

Sec-OpenEnv aims to be a welcoming project for researchers, practitioners, students, maintainers, and contributors from across the open-source and security communities.

We want collaboration here to feel:

- respectful
- constructive
- technically rigorous
- accessible to newcomers

## Expected Behavior

- Be kind, direct, and professional.
- Critique ideas, implementations, and tradeoffs rather than people.
- Assume good intent while still being honest about risks and flaws.
- Keep discussions useful for future readers.
- Help make the project more understandable, not more exclusive.

## Unacceptable Behavior

- Harassment, threats, or discrimination
- Personal attacks, insults, or derogatory language
- Doxxing or sharing private information without permission
- Repeated bad-faith argumentation or deliberate disruption
- Dismissing contributors based on experience level, background, or affiliation

## Scope

This code of conduct applies to issues, pull requests, code reviews, discussions, and project-adjacent collaboration spaces.

## Reporting

If you experience or witness behavior that violates this code of conduct, report it privately through the repository hosting platform’s maintainer contact path when possible.

## Enforcement

Maintainers may request changes in behavior, moderate or remove content, reject contributions, close discussions, or limit participation when necessary to keep the project safe and usable.
