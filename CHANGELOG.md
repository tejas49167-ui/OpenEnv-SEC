# Changelog

All notable changes to this project should be documented in this file.

## [2.1.0] - 2026-04-11

### Added

- framework-style namespace package under `src/sec_openenv/`
- compatibility package under `src/cyber_vulnerability_triage/`
- CLI entrypoint for environment discovery and serving
- expanded documentation system in `docs/`
- RFC directory and initial proposals
- GitHub issue and pull request templates
- richer examples and contributor-facing ecosystem files

### Changed

- refreshed README positioning to frame the project as a security environment framework
- improved packaging metadata and repository structure for installability and extensibility

### Preserved

- the core cyber vulnerability triage environment semantics and logic
- the existing FastAPI/OpenEnv-style runtime behavior
