# Roadmap

Sec-OpenEnv is being shaped as a long-lived security environment framework, not a single benchmark drop.

## Near Term

- deepen the bundled environments with richer datasets and more realistic artifacts
- standardize evaluation outputs and trace storage across environments
- publish more examples for custom agents and external model adapters
- expand CI to cover packaging, examples, and environment-serving smoke tests

## Mid Term

- add more security domains such as cloud misconfiguration review and identity incident triage
- introduce richer benchmark reports for repeated-run comparisons
- make extension templates easier for third-party environment authors
- add release automation and versioned compatibility guarantees

## Long Term

- position Sec-OpenEnv as the default starting point for security-focused agent environments
- support a broader ecosystem of community-contributed environments
- improve interoperability with OpenEnv-style tooling and future training pipelines

Detailed notes can continue to live in [docs/roadmap.md](docs/roadmap.md).
